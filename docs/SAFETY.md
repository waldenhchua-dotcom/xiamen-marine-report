# 数据与现场边界

程序汇集证据并检查完整性，不判断或保证现场可以下水。预报数据不是实测，参考潮位站不是水深探测点，高潮不是憩流；模型表层海流不是湾内实测潮流场。

三段报告至少要求：源日期正确、所有原件 SHA-256 正确、明确时区与潮高基准面、来源支持的参考站关系、每个变量真实格点位置、完整跨日逐时序列、目标日期的官方预警与海洋预报正文。缺失或未核实即阻断。看到栏目、收到 HTTP 200、拿到一份 PDF，均不表示审核通过。

未取得预警正文必须写“未确认/未取得”，不能写“无预警”。雷暴天气码是模型信号，不能代替官方预警。零流速和缺流速分别处理；不画缺值的方向箭头。

`UNAPPROVED_REFERENCE` 是可查看的交付标记。`VALIDATED` 表示通过确定性数据校验；`APPROVED_REPORT` 仅表示有人提交了与最终候选摘要绑定的独立报告审核记录。当前审核是可审计的人工作证，不是数字证书、身份认证或现场安全批准。

合成夹具的曲线、格点、预警正文均是测试材料，不能用作真实计划。示例图上有醒目的 SYNTHETIC / 合成标记。

HTML App 默认仅监听本机 127.0.0.1，限制一次运行一个取证/绘图任务，所有下载只允许当前任务注册的文件。它不具备公网账户认证、多租户隔离或自动清理策略；本版本不接受直接公网绑定。

API 密钥从环境读取；敏感参数清除后才进入来源记录。运行时证据留在本地忽略目录，不进入公开 Git 仓库。公开原始数据前必须另行核对数据授权。
